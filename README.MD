#Project **D.U.C.K**
##Detect, Unmanned ,Care, Keep
**앱 연동 이상고열감지, 침입자감지, 수면관리 통합 무인 케어 및 알람 서비스.**
###**ICON** : 4169E1, #202020, #FFCC01 색상만 사용, 오리 그림

###**주요 기능**
1) 전용 앱 연동으로 실시간 집 내부 영상 스트리밍 기능
2) 실시간 시계열 수면 데이터 측정, 최적의 기상 알람 기능
3) 열화상 센서로 이상온도 탐지 및 캡쳐, 앱 알림 기능
4) PIR 센서로 침입 감지, 침입 방향 캡쳐,  업스케일링 필터 적용 후 앱 알림 기능

###**구현스택**
네이버 클로바 스피치 API, Aduino, React, Postman, Python 등
